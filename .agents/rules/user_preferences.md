# User Preferences & Testing Policy

- **No Automated Browser Subagent**: NEVER launch the `browser_subagent` to open, click, or control browser windows on behalf of the user.
- **Manual Verification**: Always provide the direct local URLs (e.g., `http://127.0.0.1:5001`), CLI commands, and clear step-by-step instructions so the user can test and inspect in their own browser and terminal.
- **Indian Equities Focus**: All financial models, scanners, data pipelines, and research are strictly for Indian Equities (NSE/BSE, Screener.in, NIFTY indices, Indian Rupee ₹).
